fix(build): ldid 缺失导致 Error 127 —— 显式用 codesign 做 ad-hoc

CI 表现: 编译 ✓、链接 ✓、进入 "Generating debug symbols" 之后突然
        make Error 127（command not found），极易误判成 dsymutil 出问题。

根因（读 Theos 源码定位）：
  makefiles/targets/_common/darwin_head.mk
    ifeq ($(TARGET_CODESIGN),)
      ... ldid 找不到时 TARGET_CODESIGN = ldid   # 裸命令名
    endif
    TARGET_CODESIGN_FLAGS ?= -S
  即 Darwin 上 Theos 默认用 `ldid -S` 做 ad-hoc 签名；runner 上
  ldid 既不在 PATH 也不在 SDKBINPATH → 以裸名执行 → 127。

修复（双保险）：
  1. workflow 的 Setup Theos 里补装 ldid 到 $THEOS/bin（进 PATH，
     __executable(ldid) 检查即命中），三个来源依次回退
  2. Makefile 里 override TARGET_CODESIGN=codesign
     TARGET_CODESIGN_FLAGS='--force --sign -'
     macOS 自带 codesign，ad-hoc 对「后续还要整包重签」的 dylib 完全够用；
     用 override 保证命令行传参也覆盖不掉，CI 与本机行为一致

这样即使 ldid 三个源都拉不到，构建也不会再挂在签名这一步。
